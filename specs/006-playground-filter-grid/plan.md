# Implementation Plan: Playground Filter Grid

**Branch**: `006-playground-filter-grid` | **Date**: 2026-05-15 | **Spec**: [spec.md](./spec.md)

## Summary

Convert the Playground listing page from a static single-column Server Component list into a 2-column interactive grid with real-time search and multi-select difficulty filtering. Filter state is persisted in URL query params (`q`, `d[]`) so filtered views are shareable. All filtering is client-side; challenge data remains server-rendered.

## Technical Context

**Language/Version**: TypeScript 5, React 19, Next.js 16.2.4 (App Router)
**Primary Dependencies**: Next.js `useSearchParams`, `useRouter` (no new packages)
**Storage**: URL query params only (`localStorage` not used for this feature)
**Testing**: Manual checklist (see quickstart.md); `pnpm build` for type safety gate
**Target Platform**: Desktop/laptop browser (hub web app)
**Project Type**: Web application — Next.js App Router hub
**Performance Goals**: Filter response within same render cycle; no debounce needed at 20–50 item scale
**Constraints**: Must not break existing card link navigation; must pass `pnpm build`
**Scale/Scope**: 20–50 challenges; all in-memory client filtering

## Implementation approach

### Step 1 — Extract `ChallengeCard` component
Extract the existing inline card markup from `page.tsx` into `ChallengeCard.tsx`. No behaviour change — pure extraction and prop-typing. Verify `pnpm build` passes.

### Step 2 — Build `ChallengeFilterGrid` client component
Create `ChallengeFilterGrid.tsx` with `"use client"`. Accepts `challenges: Challenge[]`. Reads `useSearchParams()` for `q` and `d[]`. Computes `filteredChallenges` inline. Renders: search input + difficulty pills + count label + 2-column grid of `ChallengeCard`.

### Step 3 — Update `page.tsx`
- Widen container: `max-w-3xl` → `max-w-5xl`
- Replace the `<div className="grid gap-3">` map with `<ChallengeFilterGrid challenges={CHALLENGE_REGISTRY} />`
- Keep header section (title + subtitle) as-is

### Step 4 — Wire URL param updates
Inside `ChallengeFilterGrid`, implement `updateParams` helper using `useRouter().replace()` with `{ scroll: false }`. Hook search input `onChange` and pill `onClick` to it.

### Step 5 — Verify
- Manual test checklist from quickstart.md
- `pnpm build` clean
