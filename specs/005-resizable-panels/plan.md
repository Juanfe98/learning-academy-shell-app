## Summary

Replace the fixed-width 3-column layout in `PlaygroundShell` with draggable resizable panels using `react-resizable-panels` v4.11.0. Users can drag dividers between the file explorer, editor, and preview/console columns. For React challenges, a vertical divider within the right column also allows resizing preview vs. console height. No new props, stores, or data persistence in v1 — purely a layout refactor of one component.

## Implementation Phases

### Phase 0 — Research ✓

- **Decision**: `react-resizable-panels` v4.11.0
- **Rationale**: Zero external deps, ~10.9kb gzip, React 19 compatible, percentage-based sizing, no required CSS, actively maintained
- **Alternatives rejected**: custom `pointermove` (maintenance burden), `allotment` (too heavy), `re-resizable` (per-element, not panel-group)

See `research.md` for full evaluation.

### Phase 1 — Design ✓

**Panel size defaults** (% of container):

| Panel | Default | Min |
|---|---|---|
| Left column | 20% | 12% |
| Editor | 55% | 25% |
| Right column | 25% | 18% |
| Preview (vertical, react only) | 60% | 20% |
| Console+tests (vertical, react only) | 40% | 20% |

**Environment handling**: For `node-ts`, no vertical split — plain flex column in the right panel.

**Drag handle**: 4px hit area, 1px visible line, `--border-subtle` idle → `rgba(99,102,241,0.4)` hover → `rgba(99,102,241,0.5)` active.

See `data-model.md`, `contracts/ui-contracts.md`, `quickstart.md`.

### Phase 2 — Implementation (tasks.md)

1. Install `react-resizable-panels` via pnpm
2. Refactor `PlaygroundShell.tsx` — replace fixed flex widths with `PanelGroup` + `Panel` + `PanelResizeHandle`
3. Define `ColHandle` and `RowHandle` internal components
4. Branch right column on environment: vertical `PanelGroup` for react, plain flex for node-ts
5. `pnpm build` + manual verification checklist
